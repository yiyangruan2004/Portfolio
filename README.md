## Significance and method

This repository publishes Yiyang Ruan’s research-oriented engineering portfolio at `https://yiyangruan2004.github.io/portfolio/`. It uses static HTML and CSS so GitHub Pages can deploy the `main` branch directly. Replace each figure placeholder with an asset in `assets/` and replace each “Demo UI link coming soon” label with a working project link when available.

## Repository structure

- `index.html` contains the page content and project cards.
- `styles.css` contains the responsive visual design.
- `assets/` stores future project figures.
- `test-site.mjs` verifies the page structure and README rule with `node --test test-site.mjs`.
