Hydrophone Scanning System for Acoustic Field Characterization

Focused ultrasound (FUS) has demonstrated significant potential for noninvasively modulating brain activity (neuromodulation) and enabling brain-tumor biomarker sampling (sonobiopsy). Accurate characterization of the acoustic fields generated by FUS transducers is therefore essential for treatment precision, safety, and reproducibility. To address this need, I independently developed a lab-wide hydrophone scanning system for acoustic field characterization of ultrasound transducers, integrating off-the-shelf instrumentation to target commercial-grade calibration performance.

I am responsible for the entire system. The program communicates with a function generator through VISA, a PicoScope through the official PicoSDK, and two Velmex motion controllers through a serial port. The gantry system is self-assembled from three motorized stages and one free stage.

Developed in C++ using Qt, the program integrates instrument connection, configuration, and control into a single graphical user interface, with timestamped logging and message boxes that provide operational guidance and error information. Users can configure the excitation frequency, amplitude, and burst cycle count, together with the oscilloscope’s voltage range, sample count, and timebase (frequency). Manual positioning controls support incremental movement along each axis, movement to specified coordinates, and coordinate zeroing. Individual measurements coordinate oscilloscope acquisition with function generator triggering and display the captured waveform directly in the interface.

For automated volumetric scans, users define the scan boundaries and spatial step size. The program first moves the stage to the two boundary corners for safety inspection, then waits for the user to continue. During a scan, it follows a serpentine trajectory through the selected region, collecting a waveform at each position and updating the waveform display and scan progress. Pause, resume, and stop controls allow the operator to manage acquisition and change configuration during a scan.

Individual waveform captures and completed scan results are saved as CSV files with instrument settings and position information for subsequent analysis. Scan exports include pressure values calculated using the configured hydrophone sensitivity. After completing a scan, the stage returns to the intended focus.

Wireless Ultrasound-Guided Diffuse Optical Tomography System (US-DOT)

Diffuse optical tomography (DOT) uses light to estimate tissue absorption and scattering properties, providing information about blood volume and oxygenation. This project combines ultrasound-based lesion localization with functional optical imaging for breast cancer assessment. I am modernizing the acquisition architecture and developing wireless data transfer and visualization to make the system more portable and easier to operate.

I was responsible for modernizing the system architecture and enabling real-time wireless operation.

Data path: 15 LTC2326 ADCs → Cmod A7-35T FPGA → SPI → ESP32-S3 MCU→ UDP/Wi-Fi → Qt application

The A7-35T FPGA captures two's-complement 16-bit samples at 200 kHz from the ADC and buffers data from each detector channel using dedicated FIFOs. It also receives commands from the ESP32-S3 and functions as a command decoder and channel multiplexer. The ESP32-S3 serves as a wireless bridge, communicating with the A7-35T through a full-duplex SPI interface and transmitting acquired data via UDP over Wi-Fi to a Qt/C++ desktop application. The desktop application monitors device connectivity, polls selected channels, and visualizes the returned raw DOT data in real time. The native desktop build uses the real UDP link. The WebAssembly build cannot open the Qt UDP socket, so it simulates the connection and generates repeatable waveforms for all 15 channels.

Endoscopic 3D Optical Coherence Tomography for Optical Biopsy

Conventional white-light endoscopy shows tissue surfaces but provides limited information about subsurface structure. This project develops a custom catheter-based 3D optical coherence tomography (OCT) platform for high-resolution volumetric imaging, combining functional, structural, and radiomic feature analysis to support optical biopsy of endometrial cancer and colorectal polyps. My work focuses on improving catheter rotation and translation for reliable image acquisition.

I was responsible for optimizing and redesigning the motor control platform. The legacy system utilized two motors: a brushless DC motor for catheter rotation, driven by a BLS-510 motor driver, and a stepper motor for catheter push/pull motion, driven by the existing motor control system. These driver boxes were controlled by an Arduino connected to a custom graphical user interface (GUI). In the redesigned system, the brushless DC motor driver was replaced with a miniture SimpleFOC Mini v1.1, while the stepper motor system was replaced with a PKP266D28BA2 motorized stage driven by a miniture TMC2208 stepper motor driver using the default 1/8 microstepping configuration. The intermediate Arduino control code was also restructured to accomodate the changes on drivers. Additionally, the motorized stage was calibrated to accurately correlate commanded motion with physical displacement, ensuring precise and repeatable movement speeds.
